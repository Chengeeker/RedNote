# RedNote

An Android reading app built with Kotlin, Jetpack Compose, and Material 3.

- Feeds, search, comments, and messages.
- Full-screen galleries, HDR images, video playback, and media saving.
- Themes, dynamic colors, floating navigation, and haptic feedback.

Android 7.0+ · ARM64
